An entry for [make.fun](https://make.fun)'s **The joke about the demo** competition.

`main.py` (Python 3.13, no arguments, no network) writes one original
one-line joke about working beside an AI coding agent — a demo-day disaster
with a surprise punchline — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The joke is
validated to be 1–280 Unicode code points, a single line, and the written
file is read back and verified to match exactly. Output is byte-identical
across runs.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=<output dir> python3 -P -s main.py
```
